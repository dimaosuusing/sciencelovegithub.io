ScienceLove

aim assist overlay for osu!

Lightweight external tool that draws an aim assist overlay on top of osu! — no injection, no memory patches, no game file modifications.

Note: Aim Assist is fully functional. Relax, Timewarp, and Auto-bot are coming later.

How to use

1

Extract the archive

Download the .rar file and extract it anywhere.

2

Run the executable

Launch ScienceLove.exe. No installer, no admin needed.

3

Play

Launch osu! as usual. The overlay detects the game window automatically.

Features

Overlay, not injection

Draws on a transparent window. No processes hooked, no DLLs in the game.

Scripting

Lua API for custom behaviors. Still experimental — feedback welcome.

in progress

Lightweight

Single exe, ~15 MB. CPU stays under 1-2% on idle.

Profiles

Save and switch configs. Built-in editor, live preview.
